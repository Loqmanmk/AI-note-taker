# FocusNotes logo

The mark shows three sound bars turning into three lines of notes; the orange line is the part that matters for the exam.

| File | Use |
|---|---|
| `logo.svg` | The logo as a vector: scales to any size (website, print) |
| `icon-rounded.png` | The app icon with rounded corners, 1024 px: videos, social profiles, store graphics |
| `mark-white.png` | The mark alone in white, transparent background: over violet or dark video scenes |
| `mark-violet.png` | The mark alone in violet, transparent background: over white or light backgrounds |

Colors: violet `#6D5DF6` → `#8B4CF0` (gradient), brand violet `#5B4FE9`, highlight orange `#FF9D5C`, "I'm lost" orange `#E8590C`.

The app's own icon files are in `mobile/assets/` (changing them needs a new app build). They are generated from the same drawing.
